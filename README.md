# 🎮 Gamer Store - Mini Katalog Mobil Uygulama Projem

Bu repoda, "Mini Katalog Mobil Uygulama Projesi" kapsamında sıfırdan geliştirdiğim Gamer Store e-ticaret uygulaması bulunmaktadır. Projeyi gereksinimleri tam karşılamak adına **gerçek bir Android emülatör (Pixel 9)** üzerinde derleyip çalıştırdım.

## 🚀 Eklediğim Özellikler
* **Koyu Tema (Dark Mode):** Oyuncu konseptine en uygun tasarım.
* **Statik Veritabanı:** 8 farklı oyuncu ekipmanından oluşan ürün listesi.
* **Dinamik Arama Çubuğu:** Ürünleri anlık olarak filtreleyen dinamik arama motoru.
* **Sayfa Yönlendirmeleri:** Navigator.push yapısı ile Ana Sayfa -> Detay -> Sepet geçişleri.
* **Aktif Sepet Sistemi:** Ürün ekleme, silme ve anlık toplam tutar hesaplama.
* **Hata Yönetimi (Error Builder):** Resim bağlantısı kopmasına karşı uygulama çökmesini engelleyen yapı.
